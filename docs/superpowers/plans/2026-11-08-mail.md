# Mail Module Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task by task;
> independent primary-source research and final review use subagents.

**Goal:** Hoàn thành bài email NestJS và README giải thích sáu khái niệm.
**Architecture:** Controller → MailService/Map → logging decorator →
SMTP adapter hoặc mock strategy. Nest useFactory lắp ghép các provider.
**Tech Stack:** NestJS 9, TypeScript 4.9, class-validator, Nodemailer, Jest.
**Spec:** [Thiết kế](../specs/2026-11-08-mail-design.md).

## Global Constraints

- Giữ prefix `/api` chung, controller `v1/mail`, POST `send`.
- Không switch/case cho việc chọn mail provider; không sửa API đang có.
- `smtp`/`mock`; `isHtml` optional boolean; mặc định `mock` qua `.env`.
- Chỉ thêm Nodemailer và typings cần thiết, không gửi email thật khi test.

## Review Focus

- Provider lạ và default sai không được âm thầm fallback.
- Mock hoạt động khi chưa cấu hình SMTP; null/omitted provider dùng default.
- HTML chỉ được gửi dưới dạng HTML khi `isHtml=true`.
- SMTP không chấp nhận cấu hình thiếu/port sai hay báo thành công khi reject.
- Lỗi validation giữ đủ danh sách; lỗi gửi không lộ credentials/provider error.
